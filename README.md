# google-sites-builder — скилл для Claude Code

Собирает и публикует сайты на **Google Sites** (sites.google.com), управляя
закрытым визуальным редактором через `playwright-cli`. У Google Sites нет API
и загрузки HTML — всё делается кликами в залогиненном браузере, и этот скилл
хранит все отработанные приёмы работы с ним.

## Что умеет

- Полный цикл: логин-профиль → структура страниц → тексты → тема в цветах бренда →
  фоновые картинки → внутренние ссылки → общий футер → 18+/CTA-модалка (embed) → публикация.
- Три режима: уникальный сайт, сайт по референсу, близкая копия референса.
- **Готовые скрипты на каждый шаг редактора** (`scripts/js/`): текстовый тайл, layout фото+текст,
  футер, скрытие полиси, Cover, embed-модалка, тема, публикация, проверка — запускаются по одному,
  каждый шаг виден и проверяется сразу. Оркестратора нет — намеренно.
- Первый экран — **Cover-хедер** с единственной embed-модалкой 18+ фиксированного шаблона серии
  (`18+ | заголовок` → акцентная линия → два абзаца → широкая CTA на адрес самого сайта).
- **Layout-блоки** фото + текст (слева / справа / сверху / чередование) нативными «Content blocks».
- Брендовая тема (Style 1/2/3 через свотчи с Hex → Tab → Save), оригинальный логотип, обязательная фавиконка.
- Бесшовные фоновые паттерны с учётом затемнения картинок в Sites.

## Процесс (правила, выстраданные практикой)

1. **Префлайт.** Перед стартом один вопрос: «Не идёт ли сейчас другая сборка
   Google Sites?» Один Chrome-профиль тянет только одну сборку; параллель — через
   второй user-data-dir с тем же Google-аккаунтом.
2. **Референс = спецификация.** Если дан референс, его структура/фон/футер
   обязательны. Копировать старые сайты запрещено — всегда чистый лист
   (исключение: пользователь сам указал сайт-пример с того же референса).
3. **HTML-прототип главной до редактора.** Локальный макет (колонка ~944px,
   реальные тексты, фон, футер, модалка) → утверждение → только потом браузер.
   **В прототипе только то, что есть нативными блоками Sites**: текстовые секции на
   Style 1/2/3, layout фото+текст, разделитель, кнопка, Cover-хедер с одной embed-модалкой,
   белый футер. Никаких карточек, сеток, бейджей, цветного футера — их без embed не собрать.
3b. **Адрес — сразу после создания сайта.** Указан в запросе → берётся дословно; не указан →
   `<бренд>-info`, занят → скилл сам берёт ближайший похожий, без вопросов.
4. **Публикация один раз в конце.** Промежуточные проверки — DOM-eval в редакторе.
   Финальная проверка ≤15 минут, иначе URL и список находок отдаются пользователю.
5. **Тайм-бокс на упрямые контролы:** две неудачные попытки → просьба сделать
   один ручной клик (5 секунд против 30 минут обходов).

## Ключевые приёмы редактора (в references/)

| Проблема | Решение |
|---|---|
| Контролы игнорируют `.click()` | реальные клики: `mouse.move → down → pause → up` |
| Hex-цвет темы не применяется | ввод с `#` → **Tab** → **Save** (Enter не работает) |
| Фон секции не ставится по URL | только **Upload** файла в каждую секцию; галерея своего не показывает |
| Открытый file chooser блокирует всё | скормить ему файл командой `upload` |
| Ручки ресайза «мёртвые» | закрыть и заново открыть браузер |
| Правка «на живом» сайте не работает | редактировать только `/d/<siteId>/p/<pageId>/edit` |
| Модалка 18+ | единственный embed в Cover-хедере, карточка `min-height:100%`, плитка 760×968 → сетка 782×970 |
| Embed в хедер не встаёт автоматикой | проверено трижды (выделенный хедер, каретка в тексте хедера, пошаговый drag) — один ручной drag ⠿, остальное скрипты |
| Фото слева / текст справа | Insert → Content blocks → `Image and caption`; тайлы дедуплицировать по y, заливать сверху вниз с перезамером |
| Лого и фавиконка | визард темы их не грузит; лого — Themes → Edit → Images, фавиконка — Settings → Brand images |
| Футер «не красится» | сначала клик по оверлею **Edit footer**, потом палитра как у секции (Style / картинка) |
| Роли цветов ушли не туда | «Default» в Colors — свотч, не таб: править Titles/Body только после клика по явному Style N |
| Заголовки в serif | у Poppins/Montserrat/Lexend/Nunito/Lato нет греческих глифов — брать Roboto/Inter/Comfortaa |
| Фото справа / текст слева | нативно недостижимо: тайл картинки падает между заголовком и текстом, текст не тащится — только left / top / alternate |
| Header type без aria-label | искать по innerText `Header type`, затем пункт `Cover` |
| Sites автолинкует домены в тексте | убирать домен из заголовков, проверять `a[href]` на live |

## Установка

```
claude plugin marketplace add pleak88/claude-google-sites-builder
claude plugin install google-sites-builder@google-sites-builder
```

Либо просто скопируйте `skills/google-sites-builder/` в `~/.claude/skills/`.

Шаг сборки — один скрипт (сессия `playwright-cli` привязана к папке, откуда её открыли):

```
python <skill>/scripts/plan.py                                   # content.py → plan.json
python <skill>/scripts/render.py js/t_text.tpl.js _t.js BLOCKS='[...]' STYLE=2
playwright-cli -s=gs run-code --filename _t.js; playwright-cli -s=gs --raw eval "() => document.title"
```

## Требования

- Claude Code + `playwright-cli` (`npm i -g @playwright/cli`) с Chrome
- Chrome-профиль с выполненным вручную входом в Google (пароль через
  автоматизацию Google не принимает — логин один раз руками)
- Python + Pillow для генерации фоновых паттернов (опционально)

## Версии

- **2.0.0** (08.09.2026)
  - **Hard requirements** серии (раздел в SKILL.md): только модалка через embed; 3–4 блока в секции;
    фиксированный шаблон модалки (`18+ | заголовок` → линия → 2 абзаца → широкая CTA, плитка 760×968,
    карточка 470); CTA всегда на адрес самого сайта, без `target`; фон под модалкой HD-фото по тематике
    или абстракция с затемнением в файле; оригинальный логотип бренда; **обязательная фавиконка**;
    контентные фото высокие, без band-кропа; хедер только на главной; один источник текстов;
    объём слов измерять, не оценивать.
  - **Структура страниц — только из референса или ТЗ**, никогда из предыдущей сборки; **прототип — только
    нативными блоками Sites** (явный список разрешённого и запрещённого); **адрес** из запроса дословно,
    иначе `<бренд>-info` → ближайший свободный без вопросов; **ничего непроверенного на клиентском сайте** —
    сначала черновой.
  - **Готовые скрипты на каждый шаг** в `scripts/js/` (тайлы, layout фото+текст, футер, скрытие полиси,
    Cover, embed + ресайз, тема, публикация, проверка) + `plan.py` + `render.py`; сборка пошагово, на виду.
  - **Cover-хедер** как первый экран (стрелка, параллакс); embed в хедер автоматика не кладёт (три проверенных
    отрицательных пути) — один ручной drag.
  - **Layout-блок «Image and caption»** (фото слева / текст справа): дедупликация тайлов, заливка сверху вниз
    с перезамером; раскладка индивидуально на сайт — left / top / alternate (`right` нативно недостижим).
  - **Футер**: палитра доступна после клика **Edit footer**; ссылки полиси одной строкой через « · »,
    строка ссылок крупнее (Subheading).
  - **Тема**: шрифт на каждый стиль текста (Text → Select text style → Font, выбор клавиатурой); «Default»
    в Colors — свотч, а не таб; шрифты без греческих/кириллических глифов; навбар `Color when scrolled` +
    снятие `Transparent at top` под тёмное лого; перепроверять картинки темы перед публикацией.
  - Новые приёмы в `references/`: куда реально встаёт блок; кнопки с нулевым bbox; Hex через `fill`; фон
    хедера через тему; ресайз тайла после выделения; футер = последняя секция; слаги с диакритикой;
    сессия playwright-cli привязана к cwd; `copy-mode.md` переписан по шагам.
- **1.0.0** — первый релиз: полный цикл сборки,
